# Laboratorio de Red Empresarial

## Descripción

Este proyecto simula la infraestructura de red de una pequeña empresa
con varias sedes interconectadas mediante routers y switches Cisco,
utilizando Cisco Packet Tracer.

La red está formada por cuatro sedes:

- Tortosa
- Amposta
- Roquetes
- L'Aldea

El proyecto está orientado al diseño, configuración, seguridad y
administración de una infraestructura de red empresarial.

## Tecnologías y conceptos

- Cisco IOS
- OSPF
- VLAN
- 802.1Q
- Routing inter-VLAN
- EtherChannel / LACP
- DHCP
- SSH
- ACL
- Port Security
- PortFast
- BPDU Guard
- DHCP Snooping
- Dynamic ARP Inspection (DAI)

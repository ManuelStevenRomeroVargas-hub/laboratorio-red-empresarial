# 1. Descripción del proyecto

## 1.1 Introducción

Este proyecto consiste en el diseño y configuración de una infraestructura
de red empresarial multisede utilizando Cisco Packet Tracer.

La infraestructura está formada por cuatro sedes:

- Tortosa
- Amposta
- Roquetes
- L'Aldea

Las diferentes sedes están interconectadas mediante enlaces punto a punto
y utilizan OSPF como protocolo de routing dinámico.

La sede de Tortosa actúa como sede principal y cuenta con una infraestructura
de red segmentada mediante VLAN, servicios DHCP y mecanismos adicionales
de seguridad en la capa de acceso.

## 1.2 Objetivos

Los principales objetivos del proyecto son:

- Diseñar una infraestructura de red multisede.
- Implementar segmentación de red mediante VLAN.
- Configurar routing inter-VLAN.
- Implementar OSPF para el routing dinámico entre las diferentes sedes.
- Proporcionar servicios DHCP.
- Implementar redundancia en la infraestructura de red.
- Configurar EtherChannel mediante LACP.
- Implementar mecanismos de seguridad en switches y routers.
- Configurar acceso remoto mediante SSH.
- Restringir el acceso de administración mediante ACL.
- Implementar mecanismos de seguridad de Capa 2.
- Realizar pruebas de conectividad y funcionamiento de la infraestructura.
